# Manufaktura Lingwistyczna

Official website for **Manufaktura Lingwistyczna – Patrycja Rosińska-Babiarz** (English lessons in Koszalin & online).

## Features

- Responsive single-page website built with HTML, Tailwind CSS (CDN), and vanilla JavaScript
- Bilingual interface (**PL / EN**)
- Interactive monthly lesson cost calculator
- Contact form powered by **Web3Forms** with honeypot antispam protection
- Direct **WhatsApp** contact card and floating button
- GDPR / RODO consent checkbox, Privacy Policy modal, and Cookie consent banner

## Project Files

- `index.html` – main website file
- `logo.png` – brand logo
- `kobieta.png` – instructor portrait
